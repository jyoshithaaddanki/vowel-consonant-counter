# 🔤 Vowel Consonant Counter

## 📌 Project Description

**Vowel Consonant Counter** is a simple web-based application that counts the number of **vowels and consonants** in a given text. It provides a quick and easy way to analyze the characters in a sentence or word.

## 🎯 Features

* 📝 Enter any word or sentence
* 🔤 Count vowels
* 🔡 Count consonants
* 🔢 Display total character count
* ⚡ Instant results
* 💻 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Creates the webpage structure
* **CSS3** – Styles the application
* **JavaScript** – Performs character counting and calculations

## 🚀 How to Run

### Step 1: Clone the Project

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open in VS Code

Open the **Vowel-Consonant-Counter** folder in Visual Studio Code.

### Step 3: Run the Project

Open `index.html` using **Live Server**.

### Step 4: Enter Text

For example:

```text
Hello World
```

### Step 5: View the Result

The application displays:

```text
Vowels: 3
Consonants: 7
```

## 🎯 Objective

The main objective of this project is to create a simple application that automatically identifies and counts **vowels and consonants** from user-provided text.
